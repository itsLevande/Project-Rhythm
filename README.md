# Project Rhythm
A work-in-progress clone of Groove Coaster.
# About
Project Rhythm is an upcoming rhythm game that will take place in a fully customizable 3d environtment, based heavily on the Groove Coaster series. 

While this tool allows for the creation of mostly complete stages, gameplay is yet to be worked on.

Please feel free to report any issues that you may come upon. If you have any suggestions for gameplay elements / design changes, please let me know!
